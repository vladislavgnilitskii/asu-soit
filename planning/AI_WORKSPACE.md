# AI Workspace

Этот документ описывает AI-среду разработки проекта АСУ СОИТ «ТехноСервис».

Цель — минимизировать рутинную работу, использовать актуальную документацию и сохранять единый стиль разработки.

---

# Основные компоненты

## Claude Code

Основной инструмент разработки.

Используется для:

- реализации функциональности;
- анализа проекта;
- рефакторинга;
- написания тестов;
- объяснения кода;
- обновления документации.

---

## Headroom MCP

Используется для анализа проекта.

Основные задачи:

- поиск связанных файлов;
- анализ архитектуры;
- понимание структуры проекта;
- поиск похожих реализаций.

Использовать перед реализацией новых модулей и при рефакторинге.

---

## Context7 MCP

Используется для получения актуальной документации библиотек.

Приоритетные библиотеки:

- Go
- Gin
- PostgreSQL
- pgx
- React
- Docker
- Kubernetes

Не полагаться исключительно на знания модели, если документация доступна через Context7.

---

## PostgreSQL MCP

Используется для работы с реальной схемой базы данных.

Использовать для:

- анализа структуры таблиц;
- проверки индексов;
- просмотра ограничений;
- проверки внешних ключей;
- анализа производительности SQL.

Не делать предположений о структуре БД.

---

## GitHub MCP

Используется для взаимодействия с репозиторием.

Возможности:

- просмотр Pull Request;
- просмотр Issues;
- анализ изменений;
- code review;
- работа с ветками.

# Документация проекта

Перед сложными задачами использовать:

1. planning/STATE.md
2. planning/CURRENT_TASK.md
3. planning/ARCHITECTURE.md (при необходимости)

# Главные принципы

- Не усложнять архитектуру без необходимости.
- Использовать существующий код как шаблон.
- Не придумывать структуру БД — использовать PostgreSQL MCP.
- Проверять документацию через Context7.
- Обновлять документацию только по фактическим изменениям.
- Безопасность важнее скорости разработки.

---

# Цель проекта

Главная цель — не просто реализовать функциональность, а понять архитектуру, принципы проектирования и приобрести практический опыт разработки полноценной информационной системы.
