# Security Review

Проведи аудит безопасности.

Проверь:

- SQL Injection;
- Broken Access Control;
- IDOR;
- JWT;
- Password Hashing;
- Input Validation;
- утечки информации;
- обработку ошибок;
- хранение секретов;
- права доступа.

Для каждой найденной проблемы укажи:

- риск;
- возможные последствия;
- способ исправления.

Не предлагай изменения, не связанные с безопасностью.
