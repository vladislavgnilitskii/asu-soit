# Code Review

Проведи инженерное ревью изменений.

Проверь:

## Архитектура

- соответствует ли слоистой архитектуре;
- нет ли нарушения границ между слоями;
- не появилась ли лишняя логика в handler.

## Go

- idiomatic Go;
- обработка ошибок;
- context.Context;
- читаемость;
- небольшие функции;
- отсутствие дублирования.

## PostgreSQL

- параметризованные запросы;
- транзакции;
- корректные индексы;
- отсутствие SELECT *.

## Безопасность

- SQL Injection;
- IDOR;
- JWT;
- обработка входных данных;
- хранение секретов.

## Документация

Определи, нужно ли обновить:

- STATE.md
- CURRENT_TASK.md
- ARCHITECTURE.md
- README.md

Для каждого замечания укажи:

- уровень важности (Critical / High / Medium / Low);
- причину;
- рекомендуемое исправление.

Не предлагай переписывать рабочий код без веской причины.

Если критических замечаний нет,

предложи:

1. обновить документацию;

2. отметить задачу как Completed.
