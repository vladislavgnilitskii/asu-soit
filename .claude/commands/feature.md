# Feature Planning

Пользователь хочет реализовать новую функциональность.

Не приступай к написанию кода сразу.

Выполни следующие шаги:

1. Прочитай:
   - planning/STATE.md
   - planning/CURRENT_TASK.md
   - planning/ARCHITECTURE.md (если требуется)

2. Изучи существующую реализацию.

3. Найди похожие:
   - handler
   - repository
   - domain models

4. Если используются сторонние библиотеки —
   проверь актуальную документацию через Context7.

5. Составь план реализации.

6. Определи:
   - какие файлы будут изменены;
   - какие новые файлы понадобятся;
   - потребуется ли изменение БД;
   - потребуется ли обновление документации.

7. Покажи план пользователю.

Не начинай реализацию,
пока пользователь явно не подтвердит план.

После утверждения плана пользователем предложи обновить
planning/CURRENT_TASK.md.

Заполни:

- название задачи;
- цель;
- план реализации;
- список предполагаемых файлов;
- следующий шаг.

Не начинать реализацию автоматически.
