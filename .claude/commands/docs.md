# Documentation Update

Проанализируй последние изменения проекта.

Определи, какие документы необходимо обновить.

Возможные документы:

- planning/STATE.md
- planning/CURRENT_TASK.md
- planning/ARCHITECTURE.md
- planning/DECISIONS.md
- README.md
- docs/

Не изменяй ROADMAP.md без явного запроса пользователя.

Не придумывай информацию.

Если обновления не требуются — так и сообщи.
